characters/: 밥, 면, 커피, 토스트, 음료, 만두, 빈 쟁반. 민트·귤 / 블루·레몬 두 팔레트, 총 14개 SVG.
icons/: 메뉴, 장바구니, 보낸 메뉴, 주문 요약, 참여자, 설정, 보내기, 쏜다. 총 8개 SVG.
brand-icons.js: 실제 앱에 포함되는 테마 대응 SVG 원본.

음식 자체를 캐릭터로 사용합니다. 팔다리는 붙이지 않고 작은 눈, 미소, 볼 색으로 표정을 만듭니다.
원래 승인된 brand.png / brand-sky.png 로고는 그대로 사용합니다.
brand-motion.js는 로고의 세 음식 카드를 SVG 클리핑으로 나누어 순서대로 움직입니다. 원본 이미지 픽셀을 수정하지 않습니다.
움직임 줄이기를 선택한 기기에서는 튀는 모션을 생략합니다.

사용 위치: 이름 선택, 첫 화면 방 카드, 빈 장바구니, 하단 내비게이션, 방 열기, 메뉴 전송.
별도의 AI 쟁반 캐릭터 초안은 채택하지 않았고 앱/배포 에셋에서 제외했습니다.
